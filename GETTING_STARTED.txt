⚡ COMMAND REFERENCE:
════════════════════

First Time Setup:
   install.bat                      # Automated setup
   OR
   python -m venv venv              # Create virtual environment
   venv\Scripts\activate.bat        # Activate virtual environment
   pip install -r requirements.txt  # Install packages

Running the Application:
   run.bat                          # Easy run
   OR
   venv\Scripts\activate.bat        # Activate environment
   python app.py                    # Start Flask server

Stopping the Server:
   Press Ctrl+C in the terminal

Checking Setup:
   python setup_check.py            # Verify everything is ready

Accessing the Portfolio:
   http://localhost:5000           # Open in web browser


🌐 ACCESSING YOUR PORTFOLIO:
════════════════════════════

Local Access (Your Computer):
   http://localhost:5000

On Another Device (Same Network):
   1. Find your IP address: ipconfig (in Command Prompt)
   2. Look for "IPv4 Address" (usually 192.168.x.x or 10.x.x.x)
   3. Visit: http://[your-ip]:5000 on the other device

After Deployment:
   Visit your deployed URL (e.g., yourname.herokuapp.com)

🔧 TROUBLESHOOTING:
═══════════════════

Issue: "Python not found"
   Fix: Install Python from https://www.python.org
        Make sure to check "Add Python to PATH"

Issue: "Port 5000 already in use"
   Fix: Edit app.py, change port=5000 to port=5001

Issue: Profile photo doesn't appear
   Fix: Check ADD_PROFILE_PHOTO.txt for detailed instructions
        Ensure file is at: static/images/profile.jpg

Issue: Styling looks broken
   Fix: Hard refresh browser: Ctrl+Shift+R

Issue: Virtual environment not working
   Fix: Delete venv folder and run install.bat again

Issue: Module not found errors
   Fix: Run: pip install -r requirements.txt
        Make sure virtual environment is activated

💡 TIPS & BEST PRACTICES:
═════════════════════════

Photo Tips:
   • Use a professional headshot
   • Wear business attire
   • Good lighting
   • Neutral background
   • Square aspect ratio (1:1)

Content Tips:
   • Keep descriptions concise but informative
   • Use action verbs in experience descriptions
   • List skills from most to least relevant
   • Update regularly with new skills/experience
   • Fix typos before deployment

Browser Tips:
   • Works best in Chrome, Firefox, Safari, Edge
   • Test on mobile before deploying
   • Use browser DevTools (F12) to test responsiveness
   • Clear cache if seeing old version

Security Tips:
   • Don't share sensitive information (SSN, passwords, etc.)
   • Use HTTPS when deployed
   • Keep dependencies updated
   • Consider authentication if needed
